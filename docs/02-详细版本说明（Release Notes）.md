## v2.3.14（2026-09-22）——稳定性修复版

**稳定性修复版：修复远程控制场景下"看不见界面"的启动崩溃，以及导航栏「关于」图标消失。**

### 🐛 修复

- **启动即静默崩溃（远程控制场景下"看不见界面"）**
  - 现象：程序启动后界面不显示，进程无声消失（无报错、无崩溃记录）
  - 根因：音频会话枚举时对 comtypes 自动管理的 COM 字符串二次释放，导致堆损坏（0xc0000374）
  - 触发：系统有正在发声的程序时必现——远控/播放器场景下最易触发
- **导航栏「关于」i 图标消失**
  - 根因：2.3.13 懒构建改造时的遗留残骸方法覆盖了真实挂载逻辑
  - 现已恢复，点按可打开关于页
