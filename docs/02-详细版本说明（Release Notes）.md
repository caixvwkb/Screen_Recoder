## v2.4.0（2026-09-27）——ASR 架构重构版

**功能性大版本：ASR 批处理架构重构（修复数万段大文件崩溃）+ OCR 启动预热 + 全局热键改造，并合并 2.3.14 的全部稳定性修复。**

### ✨ 新增 / 改进

- **ASR 转写架构重构（"开火车"模式）**
  - 文件级串行 + 文件内段级并行：一次只解码一个文件，内存只驻留当前文件音频
  - 修复大批量转写（单文件数万段）时多个 ffmpeg 并发转码导致的内存耗尽 / 系统 DLL 报错
  - 线程池贯穿全程：模型按线程只加载一次，避免每个文件重复加载
  - 每完成一个文件立即聚合输出、释放内存，未完成文件可随时停止重传
- **OCR 引擎后台预热**
  - 启动后空闲期在独立后台线程预热 OCR 引擎池，首次点击识别秒开
  - 预热失败只记日志、不影响启动；散图录制 / PDF 输出共用同一引擎池，同步受益
- **全局热键改造**
  - 框选录制范围 **Ctrl+Alt+1** / 开始 **Ctrl+Alt+2** / 停止 **Ctrl+Alt+3**（全局常驻）
  - 手动截取保持 **Enter**（截取会话期间全局临时注册）
  - 避开浏览器 / IDE 的 Ctrl+数字占用冲突，注册稳定性大幅提升

### 🐛 修复（含 2.3.14）

- **远程控制场景下启动即静默崩溃（"看不见界面"）**
  - 根因：音频会话枚举时对 comtypes 自动管理的 COM 字符串二次释放，导致堆损坏（0xc0000374）
  - 触发：系统有正在发声的程序时必现（远控 / 播放器场景最易触发）
- **大批量 ASR 转写崩溃**：数万段长视频转写时 ffmpeg 报系统 DLL 错误（已由架构重构修复）
- **导航栏「关于」i 图标消失**：恢复点击打开关于页

### 📄 其他

- 开发文档体系精简：bug / 迭代记录走 git 提交记录，docs 只保留打包指南与版本说明
- ASR 进度逻辑复核：确认文件级进度条按"已完成文件数"跳转为设计行为，非缺陷
