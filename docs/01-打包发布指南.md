# 打包发布指南

> 只记录**最新版本**的打包做法；历史版本做法以 git 提交记录为准。
> 打包相关问题只查本文档。

## 当前版本：2.3.14（2026-09-22）

> 2.3.14 为稳定性修复版（修复启动堆损坏崩溃 + 导航栏关于图标消失），
> 无新增第三方依赖、无新增源码文件，打包命令与 2.3.13 定稿完全相同。

### 打包前（必做）

清 Nuitka 缓存，避免增量缓存带上旧模块：

```
python -m nuitka --clean-cache=all
```

### 正式打包

standalone 多文件，含图标，排除 torch/sympy/numba/llvmlite 误扫，含 OCR/ASR/音频录制依赖：

```
python -m nuitka --standalone --windows-console-mode=disable --enable-plugin=pyside6 --nofollow-import-to=torch --nofollow-import-to=sympy --nofollow-import-to=numba --nofollow-import-to=llvmlite --noinclude-qt-translations --include-package=onnxruntime --include-package-data=onnxruntime --include-package=rapidocr_onnxruntime --include-package-data=rapidocr_onnxruntime --include-package=sherpa_onnx --include-package-data=sherpa_onnx --include-package=_soundfile_data --include-package-data=_soundfile_data --include-package=imageio_ffmpeg --include-package-data=imageio_ffmpeg --include-package=soundcard --include-package-data=soundcard --include-package=lameenc --include-package=comtypes --include-package=dxcam --windows-icon-from-ico=screen.ico --output-dir=output mainwindow_fluent.py
```

### 产物

`output\mainwindow_fluent.dist\mainwindow_fluent.exe`

### 分发（打包后必做）

把 `models\` 整个文件夹拷到 exe 同级（打包不含模型，外置热加载）：

- `models\ocr\`：ch_PP-OCRv4_det / rec / cls 三个 onnx + config.json（模型结构配置）
- `models\asr\`：model.int8.onnx + tokens.txt（必需，不可删）+
  punct\model.int8.onnx（标点恢复）+ config.json
- `models\sounds\`：ok.wav / click.wav / fail.wav（操作提示音，缺失=对应档静音）

整个 dist 文件夹即为绿色版，拷走即用。

### 打包版验证清单

- exe 同级自动生成**全新默认** settings.json（深色主题、隐藏调试终端默认勾选）
- `cache\trace.log` 出现 `[路径] 程序根: ...（编译环境，exe 同级）`、
  `[OCR] 引擎加载成功：本地外置模型 ...\models\ocr`、
  `[ASR] ASR 引擎加载成功：本地外置模型 ...\models\asr`
- 批量 OCR 一个含文字的文件夹，生成的 md 应包含识别文字
- ASR 批量转写：任务清单显示文件状态；中途「取消」→ 已完成的文件输出保留、
  状态栏提示未处理数；重新开始自动跳过已完成（时间标签识别），只转写缺失的
- 视频页「音频设置」录一段带音频视频；格式选「mp3（仅音频）」应产出可播放 mp3
